习题解析器 · 轻量 Demo

docx/txt → 自动切题 → 抓取加粗/高亮/颜色关键词 → 人工校对。纯前端、零依赖、不写任何存储。
这个 Demo 只验证"解析器"这一件事（需求里风险最高、占工作量最大的一环）。
· 不依赖任何存储（不写 localStorage / IndexedDB）——因为你的存储探针还没确认，这样先跑起来不受影响。
· 已实测支持：加粗 / 高亮 / 字体颜色三色关键词、文本框（w:txbxContent）穿透、判断题多种正误写法、歧义答案标待校对。
· 已知不足：.doc 老格式不支持（请另存为 .docx）；文本框里的题会被排到末尾；复杂编号（一、二 / 1.1）暂未做。
